# Python Fundamentals

Pythonの基礎文法やプログラミングの基本概念を学習する過程で作成したコードをまとめたリポジトリです。

大学でのプログラミング学習を中心に、Jupyter Notebook（`.ipynb`）とPythonスクリプト（`.py`）を保存しています。

## 学習内容

### 1. 基本文法
- Pythonプログラミングの基礎
- 変数と関数
- 論理演算・比較演算・条件分岐
- 繰り返し処理（for文など）

### 2. データ構造
- リスト（list）
- 辞書（dictionary）
- イテラブルとイテレータ
- 内包表記

### 3. 関数・モジュール
- 関数の定義と利用
- モジュールの使い方
- モジュールの作成

### 4. ファイル操作
- ファイル入出力
- ディレクトリと木構造

### 5. オブジェクト指向プログラミング
- クラスの基本

## 使用言語・開発環境

- **Language:** Python
- **Notebook:** Jupyter Notebook
- **File Types:** `.py`, `.ipynb`

## 実行方法

`.ipynb` ファイルはJupyter Notebookや、Jupyter拡張機能を導入したVS Codeなどで開いて実行できます。

`.py` ファイルは、Pythonをインストールした環境で実行できます。

## リポジトリの目的

Pythonの基本的な文法やデータ構造、ファイル操作、オブジェクト指向の理解を深めることを目的としています。

実用的なアプリケーションや自動化ツールなどの開発成果物とは分け、基礎学習の記録として管理しています。
